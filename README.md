A collection of 20 basic Java programs covering numbers, loops, strings, arrays, conditions, and problem-solving.

Programs

1. Fizz Buzz – Prints Fizz, Buzz, or FizzBuzz.
2. Palindrome Number – Checks if a number is a palindrome.
3. Add Digits – Adds digits until one digit remains.
4. Number of 1 Bits – Counts binary 1s.
5. Count Dividing Digits – Counts digits that divide the number.
6. Steps to Zero – Reduces a number to zero.
7. Common Factors – Finds common factors.
8. Count Dividing Digits – Counts digits that divide the number.
9. Add Binary – Adds two binary numbers.
10. Binary to Integer – Converts binary to decimal.
11. Reverse String – Reverses a character array.
12. Length of Last Word – Finds the last word’s length.
13. Longest Common Prefix – Finds the common prefix.
14. Valid Palindrome – Checks a sentence palindrome.
15. Detect Capital – Checks capitalization.
16. Reverse Prefix – Reverses a word prefix.
17. String Arrays Equivalent – Compares two string arrays.
18. Goal Parser – Interprets a command string.
19. Defanging IP – Replaces . with [.].
20. To Lower Case – Converts text to lowercase.
